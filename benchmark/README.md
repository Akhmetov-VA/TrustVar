Тут живет код для инференса

1) run.ipynb - содержит пример запуска от начала до конца (загружаем датасет -> собираем промпт -> загружаем в БД -> забираем из бд шлем в langchain back -> результат складываем в БД)
2) rubia.py - скрипт загрузки промпта и данных в БД по задаче rubia
3) run.py - скрипт бесконечного цикла обработки данных постоянно обрашивает БД если в ней задачи к исполнению если есть то забирает их и складывает результат обратно
4) metrics.ipynb - содержит код расчета метрик по датасетам из бд
5) drop_pending.py - удаляет из бд все задачик со статусом pending
6) ethics.py 


## Как запустить секрипт в detach моде
1) Создаем сессию ```screen -S my_session```
2) В новом терминале запускаем наш скрипт ```/home/vadim/work/TrustLLM_ru/.venv/bin/python /home/vadim/work/TrustLLM_ru/benchmark/run.py```
    теперь можно закрыть терминал 
3) Для подключения к созданной сессии ```screen -r my_session```
